Th# Contributing to CrestCode

Thanks for your interest in contributing to CrestCode! Contributions of all kinds are welcome, including bug fixes, features, documentation, and testing.

## Reporting Issues

Before opening an issue, check whether a similar one already exists.

Please include:
- A clear description of the problem.
- Steps to reproduce it.
- Expected and actual behaviour.
- Android version and device information, when relevant.
- Screenshots or logs, if useful.

## Contributing Code

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Open a Pull Request explaining what you changed and why.

## Development Guidelines

- Follow the existing project structure and coding style.
- Keep changes focused and avoid unrelated modifications.
- Test your changes before submitting a Pull Request.
- Do not commit passwords, API keys, keystores, or other secrets.
- Respect the licenses of third-party code and dependencies.

## Commit Messages

Use clear commit messages. These prefixes are recommended:

- `feat:` New features
- `fix:` Bug fixes
- `docs:` Documentation
- `refactor:` Code improvements
- `perf:` Performance improvements
- `build:` Build system changes

## Pull Requests

Before submitting a Pull Request:

- Make sure your changes build successfully.
- Test affected functionality.
- Provide a clear description of your changes.
- Include screenshots for UI changes when applicable.
- Link any related issues.

For major changes, consider opening an issue first to discuss the approach.

## Thank You

Every contribution helps make CrestCode better. Thanks for being part of the project!
